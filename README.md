## 📌 Project Overview

This project predicts **house prices** using machine learning techniques based on features such as:

- Area
- Bedrooms
- Bathrooms
- Stories
- Parking
- Furnishing status
- Location-based features

The model is built using a **Pipeline approach** to ensure clean preprocessing and efficient training.
